Eva · Personal assistant

Hoku Gmail Integration

Gmail and Google Calendar access for the owner's personal assistant.

What the integration does

Eva helps its owner search and read Gmail, view Google Calendar events, and manage events on calendars the owner owns. Google access starts only after the owner grants permission.

  • Gmail: read and search messages. The requested permission is read-only.
  • Calendar: read calendar information and create, update or remove events on owned calendars.
  • Connection checks: renew ordinary access tokens automatically and report when the owner needs to reconnect.

Personal use

This integration is intended for its owner's personal use. It is not a public email service and does not offer public account registration. This website provides information about the integration.

Read the privacy policy for details about Google permissions, local data storage, processing and revocation.
