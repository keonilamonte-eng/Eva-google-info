# Eva Google information pages

Public information for **Hoku Gmail Integration**, Eva's personal Gmail and Google Calendar integration. These files contain only the app description, privacy policy, use information and styling.

Intended GitHub Pages address: `https://keonilamonte-eng.github.io/Eva-google-info/`.

Enable GitHub Pages under **Settings → Pages → Deploy from a branch → main → /(root)**. Do not upload Eva's application, credentials, private documents, history or backups to this repository.

The app's primary model configuration was checked before preparing the text: the existing inference provider selects a local model. Review and update the public policy whenever permissions or data practices change.
